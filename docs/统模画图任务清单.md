# 统模画图与大赛版式 — 任务清单

## 一、软件怎么选（大赛「好看 + 可控」）


| 用途                       | 推荐                                                                                               | 说明                                    |
| ------------------------ | ------------------------------------------------------------------------------------------------ | ------------------------------------- |
| **数据图（柱状、箱线、散点、直方图）**    | **Python（matplotlib）+ 本仓库脚本**                                                                    | 可重复、改数据一键重出；已用 300 dpi PNG。           |
| **概念图 / 流程图（图1、图3 类框图）** | **初稿用 matplotlib 示意**；定稿二选一：**PowerPoint / WPS 演示**（快、版式统一）或 **Inkscape（免费矢量）/ Illustrator（专业）** | 大赛评委常看「层次清晰、配色统一」；矢量插入 Word 放大不糊。     |
| **论文与排版**                | **Word 或 WPS**（与 `统模初稿.docx` 一致）                                                                 | 终稿插图用「嵌入图片」+ 题注；注意全文图号、字号一致。          |
| **统一母版（色板、字体、线宽）**       | **PPT 母版** 或 **Inkscape 模板**                                                                     | 定一套主色 + 辅色 + 中文无衬线字体（如微软雅黑），所有图导出前对齐。 |


**简要结论**：数据类坚持 **Python 出图**；版式与「大赛感」主要在 **Word 里题注与对齐** + **PPT 或矢量软件** 做概念图精修。不必为统模单独学复杂 BI；把时间放在标注质量与叙事上更划算。

## 二、本仓库已具备的出图能力

- 依赖：`requirements-viz.txt`（matplotlib、pandas、numpy）。
- 脚本：`scripts/tepsa_figures.py`  
  - 默认读 `data/tessa_psa/obs_macro_preview.csv`，输出到 `output/figures/`。  
  - 可选：`--run-id ds_batch` 等，用于子集对比。  
  - **扩展图**（与 IPW / 回归叙事对齐）：`--extended`（需 `requirements-viz.txt` 中的 `statsmodels`）。
- 建议在能用的 Python 上执行（若终端默认是 MinGW 的 `python` 且无 pip，请用本机 **Python 3.13 安装路径** 的 `python.exe -m pip` / `python.exe scripts/tepsa_figures.py`）。

## 三、任务清单（按优先级）

### P0 — 能交稿

- 用 **Python313（或已装 matplotlib 的环境）** 跑通 `scripts/tepsa_figures.py`，确认 `output/figures/` 下 PNG 齐全、中文不乱码。
- 在 Word 中为 **图1–图4** 预留位置：插入对应 PNG，宽度统一（如单栏 12–14 cm），题注格式统一（「图 x  ……」）。
- 全文检查：**图号连续**、正文首次引用与图号一致。

### P1 — 与初稿叙事对齐

- **图1 / 图3（概念）**：若评委反馈「太素」，用 PPT/Inkscape 重画框与箭头，导出 **PDF/SVG** 或 **高分辨率 PNG** 再插入 Word。
- **图2（质量–Token）**：当前 `quality_score` 含演示占位；**真人标注就绪后** 重跑脚本替换 `fig02_`*，并去掉标题里「示意」字样。
- **图4（风险–福利类散点）**：确认 `risk_class` 与纵轴指标定义与正文公式 (1)–(3) 一致后再定稿。

### P2 — 大赛观感（美化）

- 统一 **色板**（2–3 种主色 + 中性灰），避免彩虹色条抢占叙事。
- 统一 **字号**：坐标轴标签 ≥ 正文字号减 1–2 级；图题略大于轴标签。
- 导出印刷：**300 dpi** PNG（脚本已设）；若期刊/大赛要求矢量，对概念图用 SVG/PDF。
- 若需 **中英文双语图题**，定稿前一次性替换，避免混排字号不一。

### P3 — 材料与合规

- `统模初稿.docx` **仅本地保存**；仓库已通过 `.gitignore` 忽略，勿误提交。
- 若提交需「数据可得性说明」，在附录中写明：`obs_macro_preview.csv` 生成命令与字段字典链接。
